# 网站采集模块（0.16.7）

入口为顶部「网站采集」。每行输入一个网址，选择保存父目录，点击开始采集。
采集过程中输入框仍可编辑，点击「加入队列」追加域名。追加请求先落盘再交给原调度器，共用并发限制；暂停后可从任务列表恢复。已保存的域名自动从输入框移除，失败、暂停项保留；已有模板和任务记录仍可在下方查看。
通过验收的任务生成独立站点文件夹，首页为 `index.html`。选择完成任务后可本地预览、打开目录、查看报告；输出目录可交给现有站点后台的模板分配和打包流程。

## 范围与完整性

- 静态 HTTP 引擎保存 HTML、外链 JS、CSS、图片（含 srcset、常见懒加载属性）、SVG、字体、CSS `@import` / `url()` 等引用资源。站内页面继续发现，CDN 引用资源单独下载，站外网页不继续爬取。
- 默认请求头采用浏览器兼容格式并保留 CloudDeskCapture 标识，改善拒绝陌生 HTTP 客户端的网站兼容性；这不是浏览器渲染，不绕过登录或验证码。
- 新任务保留原站 URL 目录层级和静态文件名；HTML/CSS 保留检测到的编码，JS 和二进制文件保持下载字节。HTML 经解析器重写本地链接，不承诺字节级一致或动态功能完全还原。
- 无后缀页面保存为目录下 index.html；动态页面附加 .html；查询参数追加稳定标识，站外资源放入 _external/来源域名；Windows 非法名称、大小写及目录冲突做安全映射，超长路径使用 _long。无后缀或动态资源按响应类型追加扩展名以支持本地静态预览。子目录首页保留位置，并在根目录生成跳转入口。
- 同 URL 不重复下载。新任务保留不同 URL 的各自文件位置，不再因内容相同合并图片路径。旧任务沿用哈希路径和断点格式，不迁移用户已有输出目录。
- 深度下拉框选择 1–3 层，首页为第 1 层。资源引用不占页面层级；达到选定深度是正常范围边界，不算下载失败。
- 模板体积默认上限 300 MB，可在标题栏调整并保存；严格超过上限会停止该站下载，删除模板、断点及源文件缓存，继续其他站点。续采前和整理后再次检查。启动采集页会在后台清理已有任务中的超限目录；未登记的目录不删除。剩余磁盘空间不足 64 MB 时停止当前文件并给出提示。为控制解析内存和 URL 队列，保留 8 MB 文本解析阈值、20000 文件上限、可调页数上限；达到这些限制会明确报告，不能误报完整。
- 无 3 MB 体积门槛。有效的小模板正常保留，但显式样式表（含无扩展名和 CSS 导入）失败，或引用资源全部失败时为「未通过验收」，不输出为可用模板。零星非样式资源失败可标为「部分完成」。这属于静态依赖验收，不是像素级视觉一致性检测。首页失败、明显拦截页和疑似 JS 空壳也单独报告。
- `.clouddesk-capture-work` 是断点缓存父目录，以任务编号区分站点；详细报告展示域名、任务编号和路径。可选择停止且未通过验收的任务点击「清理失败缓存」，释放下载文件和文本副本，保留任务记录；继续时重新下载。正常模板不允许用此按钮删除。任务移出缓存后清理空父目录。
- 新任务可选「轻量联网」：保存 HTML、CSS（含导入）和外链 JS，图片、SVG、字体、音视频使用绝对原站链接，依赖联网及原站允许访问；不减少页面深度。默认「完整离线」保持静态资源下载。断点续采沿用任务原模式，更换模式请新建任务。
- **自动清理阈值按模板文件实际总量计算，不是 ZIP 压缩包大小。** 现有后台模板上传仍校验 300 MB ZIP，采集模块不会为了上传静默裁剪文件。
- 「已完成」仅表示配置范围内的静态下载与链接整理完成。不会执行 JS，不能保证运行时接口、模块导入、登录内容、验证码页面和交互功能离线重现。复杂动态站仍建议使用原有采集工具并人工预览效果。

## 断点与占用

- 开始采集前在后台查重：规范化网址及已记录的首页重定向地址匹配已有任务。已输出模板且已保存文件仍存在、大小一致时直接跳过，不因更换保存父目录再次下载；暂停、失败或文件缺失时复用原任务。已输出的部分完成模板可用「继续采集 / 重试」主动补齐失败项。不会猜测未验证的不同域名是同一个站点。
- 批量准备和详情读取放到后台；进度按变更任务索引更新，完成后直接使用后台返回的快照，避免主线程再次访问数据库。详情最多展示 200 个失败文件，重试仍处理全部失败项。

- SQLite 保存 URL 队列与状态，完整文件记录 SHA-256。继续时验证已保存文件，只重试缺失、损坏或失败项。
- 支持暂停、关闭后继续和中断恢复。单个未完成文件从头重下，不声称支持 HTTP Range 字节级续传。
- 等待响应、重试、下载和本地链接整理都有进度反馈；其他站点还在运行时也能查看选中任务的失败报告。报告直接给出 HTTP 状态和处理建议。
- 默认并行 2 站，每站 4 连接；全局最多 8、同来源最多 4。下载分块写盘，不把整个站点或 ZIP 装入内存。重试暂时性网络错误和 429/502/503/504；数字 Retry-After 最多等待 60 秒。
- Qt Worker 在独立线程运行 asyncio；只聚合站点进度到界面，切换其他模块不取消任务。正在执行的模块禁止卸载。
- 状态和用于重写的文本源副本在本机模块数据目录。未完成的下载放在保存目录内的 `.clouddesk-capture-work`，用于续采；只有通过验收后才移动成独立站点文件夹。站点后台自动忽略缓存目录，手动选择缓存也会拒绝。旧版零成果和小残缺结果会归入缓存，保留数据和任务记录供恢复。
- 这些运行数据不打包进便携程序，不包含浏览器账号或 Cloudflare Token。输出目录由用户选择，不删除源网站或其他本地模板。

## 采集时间与保存目录

- 每个站点独立累计运行耗时，排队和暂停不计入；续采接着累计。速度显示最近约 3 秒收到的数据量（KB/s），结束后显示累计平均速度与本地结束时间。
- 时间和传输字节数保存到任务记录。旧任务未记录的历史时间显示“未记录”；页面仍在发现时不显示不可靠的剩余时间。
- 默认在系统实际桌面创建 `WebsiteTemplates`，支持重定向桌面；可以自行选择目录并记住上次选择。旧中文默认路径切换为英文默认值，但不移动原文件；已有任务仍使用各自原保存位置。
- `metrics` 负责计时与展示数据计算，`repository` 保存统计与偏好，`controller` 处理目录用例，`ui` 只负责显示与交互。

## 职责

`models`：参数及 URL/路径身份；`repository`：持久化队列和报告；`document`：HTML/CSS/SVG 解析；`engine`：异步传输、调度和整理；`quality`：模板验收；`artifacts`：缓存与输出目录迁移；`controller`：用例与任务边界；`ui`：视图；`preview`：仅监听 127.0.0.1 的静态预览生命周期。

接入现有模块注册器，复用 Worker、表格模型与公共输入组件。没有修改 ssm-main，也没有创建新的后台上传实现。


### 0.16.8 本机待采集列表
输入内容在编辑后自动保存，安全关闭前再次保存；首次升级从未生成模板的任务记录恢复列表。已保存模板继续复用，失败和暂停的网址保留。草稿存放在本机应用数据目录，不随干净发布包分发。


### 0.16.10 任务管理
输入剩余与全部任务统计分开显示。列表按等待、采集中、暂停、失败、部分完成、已完成排序，组内较晚结束的在上方。右键确认删除会停止并隐藏任务、移除输入网址，保留磁盘文件与已保存模板去重记录。释放磁盘请在删除任务前使用“清理失败缓存”。失败任务加入队列前可选择重试、跳过移除输入或取消。续采校验完整文件，仅补缺失或损坏项；未下载完的单个文件重新请求，不支持 HTTP Range 字节级续传。


### 0.16.11 预览与删除
点击已停止任务的域名可在默认浏览器打开本地 HTTP 预览，包含未通过验收但保留首页的缓存。其他采集任务可并行运行。右键菜单统一样式，支持预览和删除。删除二次确认后会停止任务并清理专属模板目录及缓存；被占用或路径验证失败时显示删除失败供重试。


### 0.16.12 体积筛选与批量删除
显示模板文件大小，可按严格大于指定 MB 筛选，默认 1000，最低 300。勾选框独立于行选择；全选仅覆盖当前可见结果，筛选改变会清除隐藏项的勾选。批量删除先确认数量、大小及目录明细，再复用任务停止和安全清理流程。

0.16.16：采集正常结束且首页未成功保存时，自动清理该任务及关联文件、移除输入网址；暂停和已保存首页的断点保留。历史失败任务可使用“删除全部失败”批量清理。

批量选择、删除集中在“批量操作”；继续任务使用“继续采集”菜单；目录和失败缓存操作位于“更多”。删除失败会保留记录和原因，不能假报已删除。
