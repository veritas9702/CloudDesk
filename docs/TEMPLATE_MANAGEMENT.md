# 模板管理

站点后台 → 模板管理，打开后自动核实当前账户的完整站点列表。

- 占用中：原站点仍存在。未完成流程可点“继续任务”。页面数为 0 也不释放。
- 疑似已删除：选择记录，点“核实并释放”，确认后再次读取原后台；站点 ID 或编码仍存在均不释放。
- 已释放：保留原站点、模板指纹、阶段及释放时间，原任务记录仍可查询。可在当前后台为新站点选择此模板。

分配时及执行前会重新检查原站点；原站点重新出现则停止。网络/登录失败不释放。没有站点 ID 的旧记录先走恢复核实。

账户隔离：只显示当前账户历史，不自动使用其他后台凭据。其他后台使用过的模板无法由当前账户重新核实，须在原账户内处理。工具仅掌握自身记录的模板使用情况，无法识别绕过工具进行的手动复制。
