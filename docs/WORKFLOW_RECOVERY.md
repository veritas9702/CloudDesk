# 未完成流程恢复

点击“重试 / 恢复未完成流程”，选择站点。

- 上传结果未知：先打开后台核实模板是否已完整解压到上传目录。
- 未完成：不勾选“已完成”，生成恢复预览，再确认执行。
- 已完整完成：勾选“已完成”，生成恢复预览后继续同步、扫描。
- 同步或扫描结果未知时，同样核实对应步骤后再决定。

成功步骤会跳过，原模板始终绑定原站点。重启工具后仍可恢复。打包前失败且尚无绑定时，修正问题后重新预览。

点击任务行查看完整失败原因及建议。旧版本记录仅有“网络请求失败”，无法反推当时是网络、代理还是后台超时；新请求会记录错误类型和 HTTP 状态。未经后台核实，不要将未知步骤标为完成。

## 给已有站点分配模板
打开站点列表会自动加载已有站点。选中页面数为 0 且没有本机模板绑定的站点，点击“分配模板”，选择具体模板文件夹（不是父目录），核对预览后确认执行。已有绑定的未完成站点请走恢复入口。

任务记录保存在本机当前账户的数据库，进入任务记录页自动读取，显示时间、步骤、状态和结果。它记录通过本工具执行的任务，不是后台其他工具的操作日志。
