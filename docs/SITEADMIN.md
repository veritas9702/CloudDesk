# 站点后台工作流

CloudDesk 0.14.0 顶部选择「站点后台」。本模块适配 SSM 静态站点群管理台，依据本机 `ssm-main` 的登录、站点列表、建站接口实现；只读参考该项目，未修改其文件。

## 使用

1. 点击「添加后台」，保存备注、后台根地址、管理员账号和密码。支持粘贴 `/login` 或 `/sites` 页面地址，会规范化为根地址。HTTP 会明文传输密码，推荐 HTTPS。
2. 一行填写一个域名。默认编码和名称均使用域名，主域名为 `*.域名`，外链协议 `https`；可取消泛域名或切换协议。相同输入自动去重。
3. 点击「登录并预览」。工具自动调用登录接口并读取现有站点；此步骤不会创建站点。名称、编码、主域名和协议完全相同则跳过，编码或主域名冲突会阻止预览，不覆盖已有配置。
4. 核对预览，点击「确认执行」。逐站点展示结果，也可取消尚未发出的请求、导出 JSON、读取站点列表及审计。

任务通过后台自身 API 自动登录并建站，不依赖浏览器点击、扩展或自动化浏览器。按钮「打开后台网页」仅用于查看后台，使用浏览器自己的登录会话；不会向地址栏传递密码或向浏览器注入会话。它不是浏览器自动填表器。

站点创建不等于 DNS 泛解析设置，仅建站模式不上传页面；所有模式均不发布网站。新站目录、默认开关等沿用后台自身的创建行为。后台要求修改初始密码时，先在浏览器完成，再更新本机配置。站点创建需要 admin 角色。

## 可靠性与隔离

- 共用已有有限并发执行器、限速器、任务线程和审计。默认串行，最多 4 个站点并发。
- 执行前重新登录，并逐站点重新检查编码及域名冲突。15 分钟预览有效期、一次性批次防重放。
- 写入超时或服务器异常不会自动重发，标记结果未知后由用户先核实。失败不回滚已经创建的站点；单个站点失败不阻止其他站点，登录失效则停止调度。
- 每个地址 / 账号 / 密码组合有独立数据库与客户端；切换平台任务继续，切换账户会清空界面状态。
- 凭据通过现有 Windows DPAPI Vault 加密在本机 AppData；访问令牌只在内存里。列表响应中的其他业务 Token 不进入视图或导出。安装包不含账户或数据库。

## 开发接入

- `siteadmin/models.py`：账户值、地址验证、建站输入模型。
- `siteadmin/client.py`：SSM API 协议、认证、分页、响应过滤及错误处理。
- `siteadmin/controller.py`：预览、冲突检测、执行用例，无 Qt 依赖。
- `siteadmin/ui.py`：表单与结果显示。
- `workspace_jobs.py`：可复用的 Qt 工作空间作业生命周期，底层继续使用 `Worker`。
- `domain_names.py`：共享域名规范化，供 CF、GNAME 和站点模型复用。

通过既有 `register` 工厂注册模块，宿主支持 `open_module` / `unload_module`，忙碌时拒绝卸载。主界面没有开发者安装 / 卸载控件。以后增加工作流步骤应扩展控制器或独立适配器，不把业务逻辑写入界面。

## 验证边界

接口依据本机 SSM 源码；单元与 GUI 测试使用模拟后台，无真实站点创建。部署版本差异、账户白名单和权限需要首次连接实际后台验证。GUI 凭据夹具替代了测试进程中不可用的 DPAPI，生产代码仍使用原 Vault，不会回退为明文存储。


## 采集模板接入（0.14.0）

勾选「建站后上传模板 → 同步上传目录 → 扫描」，选择如 `C:/Users/Administrator/Desktop/xft/Website` 的父目录。每个直接子文件夹视为一个采集站点模板，模板原域名与新注册域名无需同名。模板按文件夹名称排序，与输入的新域名顺序配对，预览显示具体映射。预览后配置区自动收起以展示步骤，可点击「展开配置」修改。

流程：打包 → 创建 / 核对空站点 → 上传并解压 → 同步上传目录 → 扫描。压缩包直接包含模板内部文件，不额外套来源文件夹。同步会替换后台 work 工作目录；不会执行发布。已有相同配置且页面数为 0 的站点可复用，请确认其 incoming / work 中没有需要保留的未扫描内容。同步时后台自身的默认注入行为保持不变。

模板数量不足时整个预览失败，不创建站点。单模板上限为 ZIP 300 MB、原始内容 1 GB、50000 个文件，与后台限制对齐。目录必须有 HTML 页面，不支持符号链接 / 目录联接。打包及哈希按块处理，原目录只读，临时 ZIP 在任务结束后清理。

本机模块级模板清单以内容指纹和路径登记绑定；已分配模板不能换给其他站点。同内容副本或改名也不会被重复分配，原目录修改后也不会默认为未使用。上传成功后仅续跑未完成步骤，不会重新上传；所有步骤完成后该域名跳过。仅本地打包失败且尚未开始远端操作，会释放未使用的临时分配。

清单位于本机 AppData 的 siteadmin 模块目录，不含密码，跨本模块后台配置防止重复分配；各账户会话、业务审计仍独立。防重复只覆盖本机记录，无法识别此前手工上传或其他电脑的使用记录。不要删除使用清单后重新跑同一批模板。

上传 / 同步 / 扫描最长等待单次响应 5 分钟，取消不撤回已经发出的服务器操作。正在写入时断网或退出会保留待核实状态，禁止自动重发和重新分配；请先人工核实后台。成功上传后正常取消，可重新预览相同域名继续同步 / 扫描。程序不会自动回滚已完成步骤。

实现职责：`templates.py` 负责目录识别、指纹和 ZIP；`template_usage.py` 负责持久化绑定；`template_workflow.py` 负责步骤编排，复用既有 execute / Worker / Store；HTTP multipart 和长请求仍由 `siteadmin/client.py` 负责。

### 已建站后补配模板
没有勾选上传模板时，建站完成仍可补配。批量方式：保留原域名和站点设置，勾选上传模板并选择模板父目录，重新预览后确认执行；预览显示复用已有空站点。指定方式：站点列表加载站点，选中页面数为 0 的站点，点击分配模板并选择具体模板文件夹，核对预览后确认。已有页面或已有模板绑定的站点继续沿用原有保护和恢复流程。
加载站点期间显示请求阶段和耗时，避免重复提交；失败显示错误，可重新加载。

0.16.17：每个域名的依赖步骤独立执行；某域名失败仅阻止该域名后续步骤，其他域名继续（用户取消或账户认证失效除外）。结束按域名汇总失败原因。未上传且无绑定的空站点可另选模板；已绑定任务通过恢复入口继续。同步明确返回目录已完成但 ZR JS 注入失败时记录 sync_failed，修复后台问题后重试同步，不重复上传。批量预览对单个站点冲突或待核实状态列为需处理，继续预览其他站点。
