# CloudDesk

Windows 本地多平台批量管理工具。客户端 v0.16.24，支持 Cloudflare / GNAME / 站点后台 / 网站采集，浏览器权限助手 v0.1.5。

网站采集支持批量网址、静态资源下载、本地链接修正、可配置体积上限与质量验收、暂停续采、失败报告和本地预览。复杂动态页面不保证完整离线还原。使用与范围见 [采集模块说明](docs/CRAWLER.md)。

## 使用

双击 **start.bat**。它只启动 `app/releases/0.16.24/CloudDesk/CloudDesk.exe`；没有打包程序时才使用本项目 `.venv` 运行源码。

顶部切换平台，任务可以同时运行。GNAME 添加 APPID / APPKEY 后即可读取域名、批量添加或删除 DNS、修改 NS。支持四种批量输入、冲突预览和结果导出。详见 [GNAME 使用](docs/GNAME.md)。热插拔仅作为开发接口保留，用户界面不提供模块安装或移除入口，详见 [模块接入](docs/MODULES.md)。

首次点击“自动配置 Token”，按窗口提示在 Chrome / Edge 加载本地助手。选择基础或完整权限，等待网页校验成功后核对资源范围和 IP 白名单，再确认创建。第二步提供“获取公网 IP / 复制 IP”。生成的 Token 返回工具加密保存。

助手 0.1.5 的真实网页填写已由用户截图确认。更换网络时重新检查公网出口。Token、任务数据和已安装助手位于 `%LOCALAPPDATA%/CloudDesk`，不随程序目录复制。

Cloudflare 新增「自动化接入」：创建 / 复用 Zone → 配置 DNS → 站点设置 → GNAME 修改 NS（或导出手动清单），支持统一、配对、循环解析值、步骤预览、取消和按 Token 保存配置模板。详见 [自动化使用](docs/AUTOMATION.md)。

新增独立「站点后台」工作流：自动登录 SSM、批量创建泛域名站点、重复跳过、冲突保护、结果导出。详见 [站点后台使用](docs/SITEADMIN.md)。

## 开发

`setup.bat` 创建运行环境。需要浏览器回归测试时执行 `.venv\Scripts\python.exe -m pip install -r requirements-dev.txt`。

`build.bat` 使用 `requirements-build.txt` 构建到 `app/`；中间文件位于 `.build/`。以后不再建立按版本命名的程序目录。构建前退出 CloudDesk。

测试：`.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"`。

发布：`.venv\Scripts\python.exe tools/package_release.py 输出目录`，只打包当前文件，不携带开发环境、历史构建或本机凭据。

旧版清理：双击 **cleanup.bat**。脚本检查当前程序与项目路径，要求先退出 CloudDesk，只清理已列出的旧构建及缓存。保留开发环境和本机业务数据。

站点后台支持选择采集模板父目录，为新域名一次性分配模板，自动打包、上传解压、同步和扫描；使用记录本机持久化，避免重复上传。

### Cloudflare 域名接入（0.16.16）

添加域名 / Zone 进入独立接入页面：自动读取账户（唯一账户自动选择），预览创建或复用已有域名，提交原 DNS 扫描。选中域名点击核对 DNS，勾选并确认导入扫描记录；与原服务商核对邮件和其他遗漏记录后，复制或导出 `域名|ns1,ns2` 到注册商修改。刷新接入状态后可进入原有批量配置页面。无需 GNAME API。扫描是异步且不保证完整，空扫描结果不代表原域名没有解析；已有 NS 和结果按 Token 独立保存在本机。扫描不可用时可通过原有 DNS 添加 / 更新页面补齐记录。

0.16.15：Cloudflare SSL 支持自动、严格、完整、灵活、关闭；手动模式会先退出自动 SSL。DNS 名称过滤可填写 `@,*`，空记录预览会提示先添加 DNS。批量表单改为左右布局，高级参数按需展开，预览/执行显示逐域名状态、耗时和限流提示。采集列表新增状态筛选及“删除全部失败”，确认后清理失败任务关联文件，保留部分完成、已完成和运行中任务。

0.16.16：站点加载显示请求阶段与耗时，失败可重试；已有空站点支持补配模板，重新预览会明确复用站点，不重复创建。

0.16.16：采集正常结束且首页未成功保存时，自动清理该任务及关联文件、移除输入网址；暂停和已保存首页的断点保留。历史失败任务可使用“删除全部失败”批量清理。

0.16.17：批次按域名汇总结果并提供恢复 / 另选模板入口；批量预览跳过待处理域名。同步完成但脚本注入失败单独标记，恢复无需重新上传。

0.16.18：模板预览改为后台逐域名处理、按需校验候选模板；已完成任务跳过本地库扫描，显示文件扫描及校验字节进度。

0.16.18 同时纠正采集资源的 HTML 假后缀并在上传前拦截已知二进制伪 HTML。

0.16.19：客户端接入 TDK 优先的六步加工。勾选“执行六步加工”，预览时逐站生成并固定 TDK（TK=5、D=8），可点击“核对 TDK”。确认后依次执行 TDK、简繁转换（保留 TDK）、安全统计清理、外链、H1、占位符；不自动发布。新站同时勾选上传模板；已有模板跳过上传，已完成步骤不重复执行。站点列表也可选择已有站点进入六步加工。恢复时复用 TDK 和后台任务 ID；缺少任务 ID 时手动核对绑定，不能盲目重传。详见 docs/SITE_PIPELINE.md。

0.16.20：站点列表核对发布版本，自动填入未发布站点（保护手工输入），新增复制全部主域名、一行一个。六步加工可勾选“失败自动重建一次”：需选择备用模板父目录，并在执行确认中授权删除失败未发布站点及其远端目录。预检并预留其他模板后，删除、重建、上传、同步、扫描，再执行六步；保留 TDK，旧模板隔离，第二次失败停止并报告。已发生的失败也可从结果汇总进入“失败站点换模板重建一次（先预览）”。详见 docs/SITE_REBUILD.md。

0.16.21：修复 Cloudflare 账户读取结束后仍显示读取中的反馈；空账户列表从已有域名补取所属账户，失败显示具体错误。读取域名后直接显示完整域名列表，清除旧筛选。重新打开已保存 Token、连续读取、空结果及鉴权失败恢复已加入回归测试。
